Pupitre

La musique est fabriquée sur ton appareil, à l’avance et sur des fils séparés du jeu. La build ne contient aucun fichier audio et rien n’est compressé. Ouvre cette page sur chacun de tes téléphones et lance les deux essais : les mesures sont enregistrées pour qu’on compare.

Essai 1 · charge

Orchestre : « Serment »

Thème épique en ré mineur à 132 BPM, environ 60 secondes. Cordes en ostinato, cors puis trompettes au thème, chœur, timbales, caisse claire militaire, cymbales. Jusqu’à 55 voix en même temps. La forme intro · A · B · A · B · fin ne demande que 4 sections à fabriquer.

Essai 2 · synchro

Jeu de rythme : « Poche soul »

La boucle du défi musique d’aujourd’hui, rejouée par le moteur : 104 BPM, une mesure de décompte, puis la boucle quatre fois. Les notes à taper sortent de la partition, comme dans Beat Splash. Tape sur la piste (ou espace) quand une note touche la ligne.

Décalage moyen–

Avec un casque Bluetooth, le son arrive 150 à 300 ms en retard : joue une partie, puis « Caler sur mes taps » corrige ce retard. Le réglage reste enregistré sur cet appareil.

Build légèreLe jeu n’embarque que le code et la partition. Ce morceau orchestral pèse moins de 30 Ko, contre plusieurs Mo en mp3.
Qualité d’origineLe son fabriqué sur place est lu tel quel. Le pré-bake obligeait à compresser pour garder une build raisonnable.
Le jeu ne ralentit pasLa synthèse tourne dans des workers. Le fil audio ne fait que lire des tampons, le travail le moins cher qui soit, donc pas de craquement même à 55 voix.
Démarrage courtUne section répétée n’est fabriquée qu’une fois. Le moteur mesure sa vitesse sur l’appareil et ne lance la lecture que quand la suite sera prête à temps, avec une marge ×1,5.
Toujours synchroLe swing et l’humanisation sont tirés d’une graine : la beatmap tombe exactement sur les notes jouées. Les taps sont jugés sur l’horodatage de l’événement, pas sur l’image affichée.
RobusteSi une section arrive en retard, elle démarre en cours de route au bon endroit : l’horloge du morceau ne glisse jamais. Un limiteur en sortie empêche toute saturation. Si un worker tombe, le moteur reprend son travail ailleurs.
AdaptatifEn couches, chaque groupe d’instruments a sa piste : le jeu peut ajouter ou retirer les cuivres en fondu selon l’action.

Dans un jeu

import { Pupitre } from './pupitre.js';

const ctx = new AudioContext({ latencyHint: 'interactive' });
const pupitre = new Pupitre(ctx);
await pupitre.charger(partition, { onProgres: s => barre(s.faites / s.total) });

const notes = pupitre.beatmap(n => n.instr === 'caisse');   // [{ t, instr, midi, ... }]
bouton.onclick = () => pupitre.jouer();                       // le son démarre sur un geste

// à chaque image
const t = pupitre.position();                 // secondes du morceau, telles qu'entendues
// à chaque tap
const tTap = pupitre.tempsA(ev.timeStamp);    // même échelle que la beatmap

pupitre.groupe('heroique', 0, 1.5);           // couche coupée en 1,5 s
